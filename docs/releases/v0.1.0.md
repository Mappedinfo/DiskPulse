# DiskPulse 0.1.0

首个可下载安装的版本：每小时记录 Mac 磁盘用量，在菜单栏查看容量变化。

## 下载与安装

下载下方 Assets 中的 **DiskPulse-macOS-universal.zip**。适用于 macOS 14 及以上，包含 Apple Silicon（arm64）和 Intel（x86_64）两种架构，无需自行编译或安装开发工具。

1. 双击 ZIP 解压，将 `DiskPulse.app` 拖入“应用程序”或个人目录 `~/Applications`。
2. 双击打开，点击屏幕顶部菜单栏容量环即可进入控制面板；应用没有 Dock 图标。
3. 在“偏好设置”中开启“登录后自动启动”，便于持续记录。

GitHub 的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码，普通用户请选择上述安装包。

ZIP 约 0.4 MB，解压后的应用约 1.3 MB。

## 功能

- 每小时记录磁盘总容量、可用容量与已用容量；同一小时内更新同一条记录。
- 菜单栏占用比例与短动画，24 小时／7 天／30 天趋势面板。
- 暂停自动记录、手动记录、CSV 导出和可选登录启动。
- 数据仅保存在本机；不扫描文件内容，不请求完全磁盘访问或辅助功能权限。
- 关机、休眠或退出期间保留历史空缺，唤醒后记录当前小时。

## 首次打开与已知限制

安装包使用本地临时签名，**尚未经过 Developer ID 签名和 Apple 公证**。如果 macOS 提示无法验证开发者，且你确认下载来自本仓库，可在尝试打开后进入“系统设置 → 隐私与安全性”，按提示选择“仍要打开”。系统可能要求登录密码，具体步骤见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

界面交互、登录启动及长期跨休眠运行尚未完成全面验收。历史数据位于 `~/Library/Application Support/DiskPulse`，更新应用会保留记录；升级前请先从菜单栏退出旧版本。

## 已做检查

8 项核心测试已通过；通用安装包解压后通过双架构签名校验、arm64 真实采样与 CSV 读回、Rosetta 下的 x86_64 容量读取。动态依赖均来自 macOS 系统。实际运行环境为 Apple Silicon、macOS 27.0.1，尚未在 Intel 实机或 macOS 14 上运行验证。
