# DiskPulse 0.1.1

修正磁盘已用容量偏高的问题：0.1.0 使用纯空闲空间计算“已使用”，会把 macOS 可按需回收的空间也算进去，因此可能比系统设置显示的容量高很多。

## 修正内容

- 菜单栏比例和“已使用（估算）”改用系统重要用途可用空间估算；容量明细保留物理占用、纯空闲和可回收估算。
- 趋势图支持“已用空间”与“物理占用”两种口径，避免升级时出现虚假的容量骤降。
- 旧数据库自动升级并保留历史原始读数。旧记录没有可回收估算，不回填猜测值；请切换“物理占用”查看。
- CSV 和 JSON 同时区分两种口径。CSV 新增 `available_bytes`、`estimated_reclaimable_bytes`、`physical_used_bytes`、`capacity_basis`，旧记录未知字段留空。
- 无法取得系统可用估算时，界面明确显示“物理占用”。

系统可用估算与系统设置的分类统计仍可能因刷新时间、卷范围产生差异。可回收估算可能包含本地快照等，不代表 Time Machine 的精确占用；应用不会删除快照或清理文件。[Apple 的快照说明](https://support.apple.com/en-gb/102154)

## 安装与升级

下载 Assets 中的 **DiskPulse-macOS-universal.zip**，适用于 macOS 14 及以上的 Apple Silicon／Intel Mac，无需编译。

先从菜单栏退出旧版本，解压后将 `DiskPulse.app` 放到原安装位置并替换，然后打开。容量历史和偏好设置保留。

安装包仍未经过 Developer ID 签名和 Apple 公证。确认来源后，首次打开若遇到无法验证开发者的提示，请按 [README](https://github.com/Mappedinfo/DiskPulse#首次打开) 及 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 操作。

## 检查范围

14 项核心测试已通过，涵盖计量差异、旧数据库迁移、历史口径和导出。本机历史库副本迁移保留了原有行与原始容量字段；arm64 和 Rosetta 下的 x86_64 真实读取均通过。界面由用户手动验收；尚未在 Intel 实机或 macOS 14 上运行验证。
